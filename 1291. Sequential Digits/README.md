## Problem Summary

An integer has **sequential digits** if every digit is exactly one greater than the previous digit.

Given two integers `low` and `high`, return all sequential digit numbers within the inclusive range `[low, high]` in sorted order.

---

## Examples

### Example 1

**Input:** `low = 100, high = 300`  
**Output:** `[123,234]`

---

### Example 2

**Input:** `low = 1000, high = 13000`  
**Output:** `[1234,2345,3456,4567,5678,6789,12345]`

---

## Intuition

There are only a limited number of sequential digit numbers.

Using the string `"123456789"`, every sequential number can be generated by taking a contiguous substring of a suitable length. We simply generate all possible candidates whose lengths fall between the number of digits in `low` and `high`, then keep only those within the required range.

---

## Approach

1. Store the string `"123456789"`.
2. Compute the digit lengths of `low` and `high`.
3. For every possible length:
   - Generate all contiguous substrings of that length.
   - Convert each substring into an integer.
4. If the generated number lies within `[low, high]`, add it to the answer.
5. Return the resulting list.

Since numbers are generated in increasing order, the output is already sorted.

---

## Complexity

| Metric | Complexity |
|--------|------------|
| **Time** | `O(1)` — At most 36 candidate numbers are generated |
| **Space** | `O(1)` extra space (excluding the output) |

---

## Code (C++)

```cpp
class Solution {
public:
    vector<int> sequentialDigits(int low, int high) {
        vector<int> ans;
        string digits = "123456789";

        int lowLen = to_string(low).size();
        int highLen = to_string(high).size();

        for (int len = lowLen; len <= highLen; len++) {
            for (int i = 0; i + len <= 9; i++) {
                int num = stoi(digits.substr(i, len));
                if (num >= low && num <= high)
                    ans.push_back(num);
            }
        }

        return ans;
    }
};
```

---

## Key Takeaways

- Every sequential digit number is a contiguous substring of `"123456789"`.
- Enumerating all possible candidates is efficient because there are very few of them.
- The generated numbers are naturally in sorted order.
- This approach avoids brute-force checking every number in the range.
